# PrideLand 1.21.11 Migration Plan

- [x] Added `neo_version=21.11.44` to gradle.properties

## Compilation error categories

### Group 1: Block API changes (~60 errors)
- **GlassBlock / PaneBlock** — In 1.21, `StainedGlassBlock`/`StainedGlassPaneBlock` were removed. Use base `GlassBlock`/`PaneBlock` with proper properties, or check if colored glass uses different constructors.
- **DirectionalBlock / DirectionalCarpetBlock / DirectionalGlassBlock / DirectionalRainbowConcretePowderBlock** — base class import failures
- **RainbowCraftingBlock** — `BlockWithEntity` now requires `getCodec()` override
- **RainbowDoorBlock** — Constructor changed from `Settings` to `BlockSetType`
- **ModBlocks.java** — All glass/pane block declarations
- **BlockItemQueue** — may need updating

### Group 2: CustomBedBlock + Item API changes (~40 errors)
- **CustomBedBlock.java** — `isClient` field made private in 1.21 (use `isClient()` method), `onBreak` signature changed, `getStateForNeighborUpdate` signature changed, `onStateReplaced` signature changed
- **CustomElytraItem.java** — `ElytraItem` class may have been removed/moved in 1.21
- **RainbowArmorMaterial.java** — `ArmorMaterial` API reworked, `ArmorItem.Type` package changed
- **ModItems.java** — `ArmorItem` constructor changes

### Group 3: Recipe + Renderer API changes (~20 errors)
- **RainbowCuttingRecipe.java** — `CuttingRecipe` removed/renamed in 1.21
- **ModSerializers.java** — recipe serializer changes
- **CustomBedBlockEntityRenderer.java** — `BlockEntityRenderer` now takes 2 type args
- **CustomElytraFeatureRenderer.java** — `ElytraEntityModel` no longer takes type params, `FeatureRenderer` type args changed
- **RainbowSheepFeatureRenderer.java** — `FeatureRenderer` type args changed
- **RainbowSheepModel.java / RainbowSheepWoolModel.java** — `SheepEntityModel` no longer takes type params
- **RainbowSheepRenderer.java** — `EntityRenderer` type args changed

## Execution
Dispatch 3 parallel subagents, each responsible for one group.
Each subagent works on `mc-versions/1.21.11/` copy only (not root).
After all groups done, verify fabric + neoforge compile clean.
